# ZS Crypto Signals — SMART GATE

مشروع مستقل لاكتشاف وتحليل فرص **صعود وهبوط العملات الرقمية مبكرًا** على Binance Spot، مع Scoring وبحث تنبؤي قابل للاختبار، ومسارين منفصلين: Intraday وSwing.

## المرجع الرسمي للمشروع

**[اقرأ ZS_SMART_GATE_MASTER.md — الحوكمة والمواصفات الكاملة](./ZS_SMART_GATE_MASTER.md)**

هذا الملف هو المرجع الرئيسي للمتطلبات والقرارات المعتمدة والـTechnical Blueprint وسجل الأسئلة المفتوحة. نسخة Project Resources يجب أن تطابق نسخة GitHub المعتمدة؛ **المزامنة ليست تلقائية**.

## قواعد المشروع الأساسية

- المشروع مستقل تمامًا عن أي مشروع سابق، ولا تُستورد أكواد أو بيانات أو قرارات منه تلقائيًا.
- **GitHub هو المقر الدائم لجميع مكونات وبيانات المشروع**؛ جهاز Windows مخصص للتشغيل المستمر والمسح وإرسال التنبيهات فقط. الآلية التفصيلية لتخزين البيانات الكبيرة على GitHub لم تُعتمد بعد.
- بوت Telegram رئيسي يرسل **كل إشارة مكتشفة مع Score** إلى **اثنين Chat IDs**، وبوت تحليلي مستقل يرسل بيانات الإشارة التفصيلية إلى **Chat ID واحد**.
- إشارات `DOWN` قد تكون تحذير هبوط أو توصية بيع Spot مملوك أو الاثنين حسب الحالة، ولا يوجد تصريح بتداول آلي حقيقي.
- لا تُعتمد قرارات هندسية جديدة أو مصروفات أو دمج تغييرات أو تنفيذ تداول حقيقي دون عرضها على المالك وموافقته وفق الحوكمة.
- الأفضلية للنهج البسيط الذي ثبتت فائدته بحثيًا على التعقيد غير المثبت؛ يجب الفصل بين النتائج النظرية والاختبارات المنفذة فعليًا.
